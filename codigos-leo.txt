# 1. Definição do nome do grupo e criação da pasta sanitizada

def sanitize_folder_name(name):
    if not name or not isinstance(name, str):
        return "Desconhecido"
    sanitized = re.sub(r'[\\/:*?"<>|]', " ", name)
    sanitized = re.sub(r'\s+', ' ', sanitized).strip()
    return sanitized if sanitized else "Desconhecido"

# Exemplo de uso ao adicionar grupo/canal:

channel_title = sanitize_folder_name(channel_entity.title)

# Criação da estrutura de pastas:

# 4. Recomendações para melhorias robustas
- Sempre sanitizar nomes de pastas e arquivos.
- Criar subpastas para cada canal dentro do grupo.
- Logar erros detalhadamente (usar traceback.print_exc()).
- Implementar retry inteligente para downloads.
- Nomear arquivos de mídia com timestamp para evitar conflitos.
- Separar mensagens e mídias por canal.
